# Idb.Analyzers

Roslyn diagnostics that protect immutable InterfaceDB contract baseline identities.

The package works through the standard .NET analyzer mechanism used by Visual Studio, VS Code C# tooling, Rider, `dotnet build`, and CI.

Rules:

- `IDB001`: a recorded contract was removed, renamed, or moved.
- `IDB002`: a storage contract has no baseline manifest.
- `IDB003`: an existing baseline version was changed in place.
- `IDB004`: a baseline manifest is malformed.

Baseline manifests are generated by the InterfaceDB migration tool.
