# Support InterfaceDB

If InterfaceDB helps you or your business, please consider sponsoring its maintenance.
Sponsorship is entirely voluntary. Every implemented module is available under the same
[MIT license](LICENSE), whether you contribute financially or not. There are no paid
feature gates, activation checks or sponsorship requirements.

Contributions help fund bug fixes, security maintenance, documentation, release testing
and qualification on real devices. A sponsorship is a contribution toward that work;
it does not promise a response time, a particular feature or a support contract.

GitHub Sponsors setup is pending. A verified contribution link will be added here when
the maintainer's profile is ready. Until then, reproducible bug reports, documentation
improvements and tested contributions are welcome at the
[GitHub project](https://github.com/ToolMaker/InterfaceDB).
